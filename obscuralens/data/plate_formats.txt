# ObscuraLens license-plate format pack (v6.0)
# ---------------------------------------------------------------------------
# One entry per line, pipe-separated, '#' comments and blank lines ignored:
#
#     country|region|series|example|notes
#
# country  issuing jurisdiction: ISO 3166-1 alpha-2 (DE, GB, FR, ...) or a
#          two-letter + '-XX' state/province form (US-CA, AU-NSW, CA-ON).
# region   sub-national code inside the country (German city code, Indian
#          state letters, Swiss canton, US state); empty when the national
#          format carries no regional discriminator.
# series   the pattern/series flag of the entry: 'M' = current main series,
#          'O' = obsolete/historical series, 'S' = special series. The loose
#          per-country matcher derives its regex from the EXAMPLE column
#          (A-Z letters -> [A-Z], digits -> \d, separators -> optional
#          space/hyphen, everything else literal), so examples must spell
#          the shape with real slot characters.
# example  a real-shape example of the series, uppercase where the national
#          convention is uppercase.
# notes    what the format means; 'general' whenever the shape is described
#          only at confidence level (curated from public registration
#          authority descriptions, never from a single observed plate).
#
# 79 entries. Plates are deliberately matched loosely: national formats
# change per issuing year and many countries run parallel series, so a miss
# means "not in this curated subset", not "impossible plate".
# ---------------------------------------------------------------------------
