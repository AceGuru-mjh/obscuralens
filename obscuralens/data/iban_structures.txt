# ObscuraLens per-country IBAN structure pack (ISO 13616 registry).
#
# Sources:
#   * SWIFT IBAN registry, machine-readable mirror from the php-iban project
#     (globalcitizen/php-iban registry.txt, generated from the official
#     ISO 13616 registry editions)
#   * iban.com structure table, used to cross-check every shared length
#     (0 mismatches across the 85 shared countries) and to add the newest
#     entries (FK, LY, MN, SO).
#
# This is the COMPLETE published registry subset relevant to validation:
# 124 country structures including the French territorial IBANs that share
# the French layout (GF, GP, MQ, NC, PF, RE, TF, WF, YT, BL, MF, PM) and
# the West/Central African states (CI, SN, ML, BF, NE, TG, CM, GA, ...).
#
# Format: one entry per line, sorted by country code, no duplicates:
#   CC|length|bank_code_len|account_len|country_name
# * CC          - ISO 3166-1 alpha-2 country code (also the IBAN prefix)
# * length      - total IBAN length in characters (country + 2 check + BBAN)
# * bank_code_len - characters at the front of the BBAN that identify the
#   bank (per the registry's bank-identifier offsets); 0 = flat BBAN with
#   no published split
# * account_len - remaining BBAN characters after the bank identifier
#
# The IBAN mod-97 checksum itself is computed in code (iban_sources); this
# pack provides per-country length/structure knowledge for offline checks.
#
# Major economies that do NOT use IBAN (domestic systems only):
#   US (ABA routing), CA (transit/routing), CN, JP, AU (BSB), MX (CLABE),
#   IN (IFSC). RU appears below with its registry structure but Russian
#   banks operate domestic account numbers in practice.
#
# Entries from registry extensions not present in the official SWIFT
# registry (per php-iban's swift_official flag): DZ, AO, BJ, BF, CM, CV, CF, TD, KM, CI, EG, GQ, GA, GW, IR, MG, ML, MA, MZ, NE, SN, TG, UA.
