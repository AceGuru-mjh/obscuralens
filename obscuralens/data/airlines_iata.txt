# ObscuraLens offline data pack -- IATA / ICAO airline designators
# ---------------------------------------------------------------------------
# Format:      IATA|ICAO|name|country|callsign
# One entry per line, pipe-delimited, '#' comment lines and blank lines
# ignored by the loader (obscuralens/trackers/flight_sources.py and
# obscuralens/utils/data_catalog.py both parse this file).
#
# IATA codes are the two-letter designators printed on tickets and boarding
# passes (UA, BA, LH); ICAO codes are the three-letter designators used in
# flight plans and on the radio, and the callsign is the spoken radio name
# ("SPEEDBIRD" for British Airways). The authoritative registries are the
# IATA airline coding directory and ICAO Doc 8585; this pack carries a
# curated subset of the carriers an OSINT operator actually meets, including
# several historically important airlines (Pan Am, Swissair, Continental)
# because old booking records and leaks still reference them.
#
# A miss means "not in this curated subset", NOT "airline does not exist":
# several thousand active designators exist and only well-documented ones
# are shipped here.
# ---------------------------------------------------------------------------
