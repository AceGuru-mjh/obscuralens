# vendors an OSINT operator meets most: enterprise networking gear, laptop and

# manufacturers. It is offline enrichment, not the complete registry.
#
# Format: one entry per line, sorted by prefix, no duplicates:
#   AABBCC|Vendor Name
# where AABBCC is the 6-hex-digit OUI (the first three octets of an EUI-48
# MAC address, as printed in the IEEE registry).
#
# Notes:
# * A miss here means "not in this curated subset", NOT "unknown vendor" -
#   the macvendors / maclookup online sources query the full registry.
# * 52:54:00 is the QEMU/KVM default vNIC prefix. Its first octet has the
#   locally-administered bit set, so it is not an IEEE-assigned OUI;
#   Wireshark nevertheless resolves it to QEMU and so does this pack.
# * 08:00:27 (VirtualBox default) is registered to PCS Systemtechnik GmbH.
# * 00:05:69 / 00:0C:29 / 00:1C:14 / 00:50:56 are VMware vNIC prefixes;
#   00:16:3E is the Xen/XenSource prefix.
# * B8:27:EB belongs to the Raspberry Pi Foundation; DC:A6:32 and E4:5F:01
#   belong to Raspberry Pi Trading Ltd (Pi 4 / Pi 400 / CM4 generations).
# * 01:00:5E (IPv4 multicast) and 33:33 (IPv6 multicast) are IETF reserved
#   blocks, not vendor assignments; the mac tracker reports them directly
#   from the address bits, so they are intentionally absent here.
